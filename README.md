## Environment Variables

To run this project, you will need to go to the directory  
`cd my app` \
`npm install` \
`npm install @tensorflow/tf_js`

Then go to the **server** directory and, \
`cd server` \
`npm intsall` 

After installing node_modules,
in **my_app** \
`npm start`

and in **server** \
`npm start`
